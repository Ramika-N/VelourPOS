# VelourPOS

VelourPos is a high-performance, modern Point of Sale (POS) application designed to streamline retail operations with a focus on data visualization and ease of use. Built with a sophisticated dark-themed UI, it provides business owners with real-time insights into their sales and inventory levels.

Key Features:
- Interactive Dashboard: Features a custom-built KPI section that tracks daily revenue, monthly trends, and transaction counts in real-time.
- Advanced Data Visualization: Includes integrated Bar Charts for 30-day revenue trends and Donut Charts for sales-by-category analysis.
- Robust Inventory Management: A searchable and sortable product catalog that allows for quick stock updates, SKU tracking, and brand management.
- Automated Stock Alerts: Features a built-in low-stock alert system that highlights items needing immediate reorder to prevent stockouts.
- Detailed Transaction Logging: Maintains a secure and organized history of all recent sales, including timestamps, cashier details, and payment methods.
- Modern Java Swing UI: Utilizes custom Graphics2D rendering and rounded component designs to provide a professional, desktop-native experience.
